# Nova Studio — Business Website Demo

A responsive HTML/CSS/JavaScript business website.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Netlify Forms

The contact form uses Netlify Forms. After deploying the site to Netlify, form submissions can be viewed from the site's Forms area.

## How to customize

Edit `index.html` for:
- business name
- text
- services
- projects
- email/location

Edit `style.css` for:
- layout
- typography
- spacing
- visual design

Edit `script.js` for:
- navigation
- dark mode
- other interactions
